🛠️ Herramientas Vitales de Modelado Poligonal

Estas 6 operaciones generan el 90% de cualquier objeto tridimensional.

Solo en Edit Mode [Tab]
E Extrude

Extrusión

Genera nueva geometría tirando hacia afuera o empujando caras/bordes.

Alt + E : Menú avanzado
I Inset

Inset (Inserción)

Crea un contorno interior concéntrico sobre una o varias caras seleccionadas.

I dos veces : Inset individual
Ctrl + R
Loop Cut

Loop Cut

Inserta cortes perimetrales continuos. Usa la rueda del ratón para sumar cortes.

Scroll rueda : Sumar divisiones
Ctrl + B
Bevel

Bevel (Bisel)

Redondea y suaviza esquinas duras. Es el secreto para renders fotorrealistas.

Shift + Ctrl + B : Biselar Vértices
K Knife

Cuchillo (Knife)

Permite trazar cortes libres sobre cualquier polígono. Pulsa Enter al terminar.

C : Cortar en ángulo recto
F M
Fill / Merge

Rellenar y Unir

F crea aristas o caras entre vértices. M fusiona vértices redundantes.

M > By Distance : Limpieza
⚠️

El Error #1 de Estudiantes

Escala No Normalizada

Si escalas un objeto en Object Mode sin aplicar la escala, tus modificadores (como Bevel o Subdivision) se deformarán de manera desigual.

Solución obligatoria:
Ctrl + A > Scale
